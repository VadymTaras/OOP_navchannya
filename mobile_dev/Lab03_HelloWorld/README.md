## Опис проєкту

Перший мобільний застосунок на Flutter SDK. Демонструє структуру віджетів у Flutter (`MaterialApp`, `Scaffold`, `AppBar`, `Center`, `Column`, `ElevatedButton`), підтримку зміни стану та роботу механізму Hot Reload.

## Структура файлів

- `main.dart` — точка входу Flutter додатку, дерево віджетів та обробка взаємодії;
- `pubspec.yaml` — маніфест конфігурації та залежностей проекту.

## 📌 Опис проєкту

Даний навчальний Flutter-застосунок (**«Real-Time Hardware & Telemetry Monitor»**) розроблений у межах Практичної роботи №8. Застосунок демонструє повноцінне використання реактивної та асинхронної моделі мови Dart:
1. **Одноразові асинхронні операції (`Future`, `async`/`await`):**
   - Імітація сканування апаратного вузла, опитування шин та калібрування сенсорів із затримкою 2.5 секунди через `Future.delayed`.
   - Реактивна візуалізація стану завантаження, обробка помилок та показ готових даних за допомогою віджета `FutureBuilder`.
2. **Безперервні потоки подій у реальному часі (`Stream`, `StreamController.broadcast`):**
   - Періодична генерація телеметричних пакетів (навантаження CPU, робоча температура, використання оперативної пам'яті, швидкість мережі) кожну 1 секунду.
   - Живе оновлення користувацького інтерфейсу через віджет `StreamBuilder`.
   - Інтерактивне керування потоком: призупинення (`pause`), поновлення (`resume`), скидання лічильників (`reset`).
   - Симуляція аварійного збою обладнання через передачу помилки у потік (`addError`) та перевірка обробки у `snapshot.hasError` з можливістю гарячого відновлення.

## 🧠 Ключові теоретичні концепції Dart Async

### 1. Event Loop та черги виконання (Queues)
Dart виконується в однопотоковому ізоляті (Isolate) на базі неблокуючого циклу подій (**Event Loop**), що керує двома чергами з різним пріоритетом:
- **Microtask Queue (Черга мікрозадач):** Має абсолютний пріоритет. Використовується для коротких внутрішніх дій платформи (наприклад, `scheduleMicrotask`). Поки черга мікрозадач не стане повністю порожньою, Event Loop не береться за звичайні події.
- **Event Queue (Черга подій):** Обслуговує зовнішні події введення-виведення (I/O, кліки, таймери `Timer.periodic`, завершення запитів `Future.delayed`, сокети).

### 2. Future та синтаксичний цукор async/await
- `Future<T>` представляє результат обчислення, який з'явиться в майбутньому (або завершиться помилкою).
- Ключове слово `async` перетворює функцію на генератор `Future`.
- Ключове слово `await` призупиняє виконання поточної функції до завершення `Future`, не блокуючи головний потік UI (дозволяючи Event Loop обробляти інші події анімації та взаємодії).

### 3. Stream та StreamController
- `Stream<T>` — це послідовність асинхронних подій у часі (на відміну від `Future`, який повертає лише одне значення).
- **Single-subscription Stream:** Дозволяє лише одного підписника. Якщо спробувати підписатися двічі — виникає виняток `StateError`.
- **Broadcast Stream (`StreamController.broadcast`):** Дозволяє підключатися кільком незалежним слухачам одночасно в будь-який момент часу. Ідеально підходить для шин подій, системної телеметрії та UI-віджетів.

### 4. Реактивні віджети FutureBuilder та StreamBuilder
- `FutureBuilder` підписується на `Future` і перебудовує дерево віджетів відповідно до зміни `snapshot.connectionState` (`none` ➔ `waiting` ➔ `done`), автоматично відображаючи `CircularProgressIndicator` або результат/помилку.
- `StreamBuilder` підписується на `Stream` і реактивно викликає метод `builder` при кожному надходженні нового елемента (`snapshot.connectionState == ConnectionState.active`), появі помилки (`snapshot.hasError`) або закритті потоку (`ConnectionState.done`).

## 🚀 Інструкція із запуску

### Вимоги:
- Встановлений Flutter SDK (версія 3.0.0 або новіша)
- Dart SDK 3.x
- Емулятор Android, пристрій через ADB або десктопний тарґет (Windows / Linux / macOS / Web)

### Команди:
```bash
# 1. Перехід у директорію проєкту
cd mobile_dev/Lab08_Async

# 2. Отримання залежностей
flutter pub get

# 3. Запуск застосунку
flutter run
```

## Про проєкт: Smart Home & Lab Navigator

Демонстраційний інженерний мобільний застосунок на базі Flutter Material 3, що реалізує багаторівневу систему навігації та передачі даних для лабораторної IoT-інфраструктури.

### Реалізований функціонал роутингу:
1. **Іменовані маршрути (Named Routes):**
   - Централізований клас констант `AppRoutes` (`/`, `/device-details`, `/device-edit`, `/about`, `/telemetry-history`).
   - Реєстрація у таблиці `MaterialApp.routes` для статичних переходів.
2. **Динамічний генератор маршрутів (`onGenerateRoute`):**
   - Сувора типізація та валідація вхідних аргументів через `RouteSettings.arguments`.
   - Захист від передачі невалідних типів даних та відображення діагностичного екрана помилок.
3. **Обробка невідомих переходів (`onUnknownRoute`):**
   - Екран 404 (Fallback screen) із кнопкою безпечного скидання навігаційного стека `Navigator.pushNamedAndRemoveUntil`.
4. **Асинхронний обмін даними між екранами:**
   - Перехід на екран деталей `DeviceDetailScreen` та редагування `DeviceEditScreen`.
   - Повернення модифікованого екземпляра сутності `DeviceItem` через `Navigator.pop(context, updatedDevice)`.
   - Отримання результату через `await Navigator.pushNamed(...)` з миттєвим реактивним оновленням батьківського списку приладів та показом спливаючого сповіщення `SnackBar`.
5. **Захист від випадкової втрати незбережених змін:**
   - Інтеграція сучасного API `PopScope` (Flutter 3.12+ / 3.16+) з перехопленням як системного жесту/кнопки "Назад", так і навігаційної кнопки в AppBar.
   - Діалогове вікно підтвердження `AlertDialog` ("Залишитися" / "Скасувати зміни").
6. **Комбінована дворівнева навігація:**
   - `BottomNavigationBar` (`NavigationBar` у Material 3) з 3 вкладками («Обладнання», «Моніторинг», «Налаштування») на базі `IndexedStack` (збереження стану скролу).
   - Бічне висувне меню `Drawer` із заголовком профілю студента `UserAccountsDrawerHeader`.

## Інструкція запуску

1. Встановіть Flutter SDK (версія 3.16 або новіша).
2. Запустіть встановлення залежностей:
   ```bash
   flutter pub get
   ```
3. Запустіть додаток на емуляторі або підключеному пристрої:
   ```bash
   flutter run
   ```

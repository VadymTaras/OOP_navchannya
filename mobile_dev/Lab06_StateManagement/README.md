## 📌 Опис проєкту

Проєкт демонструє побудову архітектури керування станом (State Management) у Flutter-застосунку без залучення важких сторонніх залежностей на базі стандартних реактивних примітивів Flutter:
- `ChangeNotifier` — основа реактивного стану моделі даних;
- `ListenableBuilder` — високоефективне точкове оновлення дерева віджетів без перебудови всього інтерфейсу;
- Поділ стану на **Ephemeral State** (локальний стан екрана: пошук, фільтри категорій) та **App State** (глобальний стан кошика покупок, лічильник кількості одиниць, знижкові промокоди та перемикання теми застосунку `ThemeMode`).

---

## 🏗️ Архітектура та структура коду

1. **Моделі даних (`Product`, `CartItem`)**:
   - `Product`: сутність товару (ідентифікатор, назва, категорія, ціна, піктограма, опис).
   - `CartItem`: позиція у замовленні з динамічною кількістю та розрахунком `totalPrice`.

2. **Менеджери стану**:
   - `ThemeStateManager` (`ChangeNotifier`): керує світлою/темною темою застосунку з нотифікацією слухачів.
   - `CartStateManager` (`ChangeNotifier`): бізнес-логіка додавання, видалення, зміни кількості товарів, розрахунку проміжних та фінальних сум, валідації промокодів.
   - `AppStateContainer`: контейнер-синглтон сервісів для централізованого доступу.

3. **Інтерфейс користувача (UI)**:
   - `SmartShopApp`: кореневий віджет із реактивним реагуванням на зміну теми через `ListenableBuilder`.
   - `CatalogScreen`: каталог пристроїв і датчиків, локальний рядок пошуку (`StatefulWidget`), фільтрація за категоріями, бейдж кошика з динамічним лічильником.
   - `_ProductCard`: картка товару з точковим слуханням стану лише свого товару.
   - `CartScreen`: повний огляд кошика, інтерактивна зміна кількості, застосування промокоду (`STUDENT20`, `FLUTTER10`), підсумковий розрахунок та оформлення.

## 🚀 Запуск проєкту

1. Переконайтеся, що встановлено Flutter SDK (версії 3.0.0 або новішої):
   ```bash
   flutter --version
   ```

2. Завантажте залежності:
   ```bash
   flutter pub get
   ```

3. Запустіть застосунок на емуляторі, підключеному Android-пристрої або у Chrome:
   ```bash
   flutter run
   ```

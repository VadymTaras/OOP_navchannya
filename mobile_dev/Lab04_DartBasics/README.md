## Опис проєкту

Проєкт демонструє базові та просунуті концепції мови Dart:
- Базові типи даних, робота зі змінними (`var`, `final`, `const`);
- Умовні конструкції та цикли;
- Функції, позиційні та іменовані параметри, стрілочні функції;
- Колекції (`List`, `Set`, `Map`) та робота з ними;
- ООП: класи, конструктори, іменовані конструктори, гетери/сетери, наслідування та міксіни;
- Sound Null Safety та обробка винятків (`try-catch-finally`).

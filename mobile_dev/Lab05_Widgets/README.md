## 📱 Опис проєкту: «Інженерний диспетчер завдань (Hardware Task Manager)»

Інтерактивний кросплатформний мобільний застосунок, розроблений на Flutter SDK, який демонструє практичне використання базових та інтерактивних віджетів:
- **Дерево віджетів та стан:** `StatelessWidget` (структурні та презентаційні компоненти), `StatefulWidget` (динамічний стан, життєвий цикл `initState`, `build`, `dispose`);
- **Макети розміщення (Layout):** `Scaffold`, `AppBar`, `Container`, `Column`, `Row`, `Expanded`, `SingleChildScrollView`, `Card`, `Wrap`;
- **Динамічні списки:** `ListView.builder` з підтримкою видалення через `Dismissible` (swipe-to-delete) та відновлення стану;
- **Форми та валідація:** `Form`, `GlobalKey<FormState>`, `TextFormField` з валідацією обов'язкового заповнення та мінімальної довжини;
- **Компоненти введення та вибору:** `DropdownButtonFormField` (вибір категорій та пріоритетів), `FilterChip` (інтерактивна фільтрація списку), `SwitchListTile` (тригер терміновості), `Checkbox` (позначка завершення);
- **Зворотний зв'язок та діалоги:** модальне вікно `showDialog` з `AlertDialog` та локальним станом `StatefulBuilder`, спливаючі сповіщення `ScaffoldMessenger` та `SnackBar` з дією повернення.

## 📁 Структура каталогу

- `main.dart` — повний вихідний код Flutter-застосунку;
- `pubspec.yaml` — маніфест конфігурації проєкту, версії SDK та Material Design;
- `README.md` — інженерний опис лабораторної роботи.

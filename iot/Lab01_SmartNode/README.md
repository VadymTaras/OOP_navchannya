## Опис проєкту

Проєкт реалізує базовий периферійний вузол Інтернету речей на базі мікроконтролера ESP32 та кліматичного сенсора DHT22. Вузол підключається до Wi-Fi мережі, періодично зчитує показники температури і вологості та формує JSON-пакети для подальшої публікації в MQTT-брокер.

## Структура файлів

- `esp32_dht22_node.ino` — скетч для мікроконтролера ESP32 (Arduino C++).

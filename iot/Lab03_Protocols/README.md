## 🎯 Опис проєкту

Проєкт присвячено практичному дослідженню архітектури, особливостей та ефективності прикладних протоколів передачі даних в Інтернеті речей (IoT): **MQTT**, **CoAP**, **HTTP/REST** та **WebSocket**.

У межах практичної роботи розроблено прошивку для мікроконтролера **ESP32 DevKit v1** на мові **Arduino C++**, яка реалізує роль інтелектуального клієнта телеметрії з повним життєвим циклом MQTT-з'єднання:
1. **Підключення та відмовостійкість:** автоматичне перепідключення до Wi-Fi та MQTT-брокера при обривах зв'язку без блокування основного циклу виконання.
2. **Механізм Last Will and Testament (LWT):** автоматична публікація статусу `offline` брокером у разі аварійної втрати живлення або каналу зв'язку вузла (із прапорцем `retain=true` та `QoS=1`).
3. **Публікація телеметрії (Telemetry Publisher):** циклічна генерація та публікація структурованих JSON-пакетів із сенсорними даними (температура, вологість, освітленість, системні метрики RSSI, uptime, вільна оперативна пам'ять Free Heap).
4. **Асинхронне керування (Actuator Subscriber):** підписка на топік команд для дистанційного перемикання силового реле та індикаторного світлодіода з відправкою підтвердження нового стану (State Feedback).

## 📡 Дерево топіків MQTT (Topic Architecture)

| Топік | Напрямок | QoS | Retain | Опис та призначення |
|:------|:--------:|:---:|:------:|:--------------------|
| `devices/esp32_sensor_01/status` | Публікація (ESP32 / Broker LWT) | 1 | `true` | Життєвий цикл пристрою: `online` при запуску, `offline` через LWT заповіт |
| `devices/esp32_sensor_01/telemetry` | Публікація (ESP32) | 0 | `false` | Періодичний потік телеметрії сенсорів (кожні 5 секунд) |
| `devices/esp32_sensor_01/control` | Підписка (ESP32) | 1 | `false` | Вхідні команди керування реле та індикатором від користувача/сервера |
| `devices/esp32_sensor_01/state` | Публікація (ESP32) | 1 | `true` | Підтвердження актуального фізичного стану виконавчих пристроїв |

## 📄 Формати повідомлень (JSON Schemas)

### 1. Статус доступності (`devices/esp32_sensor_01/status`):
```json
{
  "status": "online",
  "ip": "192.168.1.105",
  "firmware": "v1.3.0",
  "free_heap": 284120
}
```

### 2. Пакет сенсорної телеметрії (`devices/esp32_sensor_01/telemetry`):
```json
{
  "seq": 42,
  "device_id": "ESP32_Taras_SensorNode_01",
  "temp_c": 23.4,
  "humidity_pct": 57.2,
  "light_pct": 68.5,
  "relay": false,
  "led": true,
  "rssi_dbm": -58,
  "uptime_sec": 210,
  "free_heap": 283904
}
```

### 3. Команда керування (`devices/esp32_sensor_01/control`):
```json
{
  "relay": true,
  "led": true
}
```
*(Підтримуються також прості текстові команди: `RELAY_ON`, `RELAY_OFF`, `LED_ON`, `LED_OFF`).*

### 4. Підтвердження стану (`devices/esp32_sensor_01/state`):
```json
{
  "device_id": "ESP32_Taras_SensorNode_01",
  "trigger": "command_processed",
  "relay": true,
  "led": true,
  "timestamp": 210450
}
```

## ⚙️ Апаратно-програмні вимоги та запуск

1. **Мікроконтролер:** ESP32 (WROOM-32 / NodeMCU DevKit v1) або симулятор **Wokwi**.
2. **Необхідні бібліотеки Arduino:**
   - `PubSubClient` (автор Nick O'Leary) v2.8+
   - `ArduinoJson` (автор Benoit Blanchon) v6.x / v7.x
   - Вбудований стек `WiFi.h` для ESP32 Core.
3. **MQTT Брокер:** будь-який стандартний брокер MQTT v3.1.1 (наприклад, локальний `Eclipse Mosquitto` на порту 1883, або публічний тестовий кластер `broker.emqx.io`).
4. **Моніторинг:** утиліти **MQTT Explorer**, **mosquitto_sub** або консольний клієнт для спостереження за деревом топіків `devices/esp32_sensor_01/#`.

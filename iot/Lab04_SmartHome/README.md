## 1. Призначення проєкту

Даний проєкт реалізує комплексну інтелектуальну систему домашньої автоматизації (Smart Home Automation System) з централізованим керуванням, підтримкою протоколу MQTT та модульним механізмом бізнес-правил (Rule Engine).

Система об'єднує гетерогенні прилади, сенсори та актуатори:
1. **Клімат-контроль (Climate Controller):** термостат з зональним регулюванням та гістерезисом проти брязкоту контактів реле (relay chattering).
2. **Розумна розетка (Smart Energy Plug):** телеметрія активної потужності (Вт), струму (А), напруги (В), накопиченого обліку споживання (кВт·год) та аварійний захист від перевантаження (Overload Protection).
3. **Підсистема безпеки та безаварійності (Security & Safety):** датчики руху та присутності (PIR), сенсори затоплення водою, моторизований кульовий кран перекриття стояка.
4. **Механізм бізнес-правил (Rule Engine):**
   - *«Аварійне знеструмлення при протіканні»*: моментальне перекриття води краном та знеструмлення побутової техніки у вологій зоні.
   - *«Енергозбереження при відсутності мешканців»*: автоматичний перехід клімату в режим ECO при простої датчиків руху, вимкнення енергоємних приладів (бойлер).
   - *«Нічний режим»*: адаптація кліматичного профілю для сну.

## 2. Структура каталогу

- `smart_hub.py` — центральний контролер будинку (Smart Home Hub), Rule Engine та підсистема журналювання.
- `devices_simulator.py` — симулятор сенсорів та виконавчих механізмів.
- `config.json` — конфігураційні параметри зон, приладів, тарифів та порогових значень.
- `requirements.txt` — зовнішні залежності (`paho-mqtt`).
- `smart_home_telemetry.jsonl` — журнал телеметрії та системних подій у форматі JSON Lines.

## 3. Встановлення та запуск

### 3.1. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3.2. Автономний запуск демонстраційного циклу
Проєкт підтримує автономну роботу без окремо піднятого MQTT-сервера завдяки вбудованій шині зворотних викликів:
```bash
python smart_hub.py
```

Під час виконання демонструється послідовне проходження 5 життєвих циклів та сценаріїв:
1. Опитування мікроклімату та спрацьовування нагрівача за гістерезисом.
2. Активація «Нічного режиму».
3. Захист розетки від перевантаження за потужністю (>2700 Вт).
4. Виявлення відсутності мешканців (Away Mode) та переведення в енергозбереження.
5. Аварія затоплення: моментальне закриття крана та відключення пральної машини.

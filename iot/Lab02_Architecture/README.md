## Опис проєкту

Проєкт реалізує 4-рівневу архітектуру системи Інтернету речей (IoT) на прикладі автоматизованого вузла клімат-контролю «розумної теплиці»:
1. **Рівень сприйняття (Perception Layer):** Сенсор температури та вологості DHT22, аналоговий датчик вологості ґрунту, реле 5V Songle з оптопарою PC817, світлодіод індикації;
2. **Мережевий транспорт (Network Layer):** Wi-Fi 802.11 b/g/n, протокол MQTT v3.1.1 (порт 1883), обмін телеметрією у форматі JSON;
3. **Хмарний та серверний рівень (Cloud/Middleware Layer):** Брокер EMQX / Eclipse Mosquitto, сервер автоматизації OpenHAB 3;
4. **Рівень додатків (Application Layer):** Дашборд OpenHAB HABPanel, панель моніторингу та бізнес-правило адаптивного увімкнення вентиляції за гістерезисом.

## Структура файлів

- `esp32_smart_greenhouse.ino` — прошивка мікроконтролера ESP32 (Arduino C++);
- `openhab/greenhouse.things` — опис каналів MQTT Things у OpenHAB;
- `openhab/greenhouse.items` — семантична модель параметрів (температура, вологість, стан реле);
- `openhab/greenhouse.rules` — скрипт автоматичного керування вентиляцією за порогом 24.0°C.

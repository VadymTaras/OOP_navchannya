# Recipe Finder - Async API Web Application (Variant-5)

Асинхронний веб-додаток для комплексного пошуку рецептів здорової їжі, розрахунку харчової цінності (БЖУ) та ведення списку улюблених страв. Проєкт повністю адаптовано для стабільної та автономної локальної роботи без обов'язкового використання локального веб-сервера.

## 🚀 Функціональні можливості

- **Комплексний пошук страв:** Інтеграція з Spoonacular API для фільтрації рецептів за дієтами (Keto, Vegan тощо), часом приготування та калорійністю.
- **Локалізація інтерфейсу:** - Повний переклад головної панелі керування, фільтрів, індикаторів статусів та таблиці БЖУ.
  - Миттєвий локальний переклад популярних у Києві запитів (борщ, вареники, котлета по-київськи тощо) за вбудованим словником.
  - Надійне відображення інгредієнтів та інструкцій мовою оригіналу (англійською), що гарантує 100% збереження оригінальних цифр, мір ваги та структури тексту від API.
- **Локальне сховище (Кешування):** Збереження результатів пошуку та детальної інформації про страви в localStorage для економії лімітів API, а також ведення списку улюблених рецептів.
- **Тестування:** Вбудований автономний тест-сьют для перевірки 12 асинхронних та негативних сценаріїв.

## 📂 Структура проєкту

Проєкт організовано за класичною модульною статичною архітектурою без ES6-модулів (для сумісності з протоколом file:///):

- assets/
  - style.css          - Стилі інтерфейсу (валідовано за правилами UI/UX)
- src/
  - dictionary.js      - База даних для перекладу київських страв та елементів інтерфейсу
  - api.js             - Модуль мережевих запитів до Spoonacular API, кешування та валідації
  - app.js             - Головний контролер інтерфейсу, улюблених страв та рендерингу DOM
  - api.test.js        - Автономні комплексні асинхронні тести програми
- index.html             - Головна сторінка додатку
- tests.html             - Сторінка запуску та візуалізації тестів

## 🛠 Налаштування та запуск

1. Клонування репозиторію:
   git clone https://github.com/your-username/js-async-api-variant-5.git

2. Активація API-ключа:
   - Відкрийте файл src/api.js.
   - У рядку 2 замініть значення константи API_KEY на ваш власний діючий токен, отриманий у кабінеті Spoonacular:
     const API_KEY = "ваш_реальний_токен_spoonacular";

3. Запуск програми:
   - Завдяки відмові від type="module", додаток не блокується політикою CORS для ES6-модулів у браузерах.
   - Просто двічі клацніть по файлу index.html у провіднику, щоб відкрити його через протокол file:///... або запустіть за допомогою вбудованого веб-сервера CLion.

## 🧪 Тестування програми

Для перевірки працездатності розроблено систему з 12 комплексних тестів, розділених на два логічні блоки для наочності:
- Базові тести програми: Перевірка ініціалізації об'єктів, методів API та локального перекладу страв.
- Розширені сценарії тестування: Негативне тестування помилок сервера (статуси 402 та 500), робота з граничними символами пошуку, а також перевірка серіалізації та роботи з localStorage.

Щоб переглянути результати, відкрийте у браузері файл tests.html. Весь звіт із коментарями буде згенеровано на екрані автоматично.

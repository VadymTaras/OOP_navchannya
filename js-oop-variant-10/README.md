# Керування зоомагазином

Цей проєкт є модульним веб-додатком для автоматизації обліку, вакцинації та продажу тварин у зоомагазині. Програма реалізована на чистій мові JavaScript (ES6+) з використанням об'єктно-орієнтованого програмування.

## Функціонал програми

- **Об'єктна модель тварин**: Реалізовано базовий клас "Pet" та три класи-спадкоємці: "Dog", "Cat", "Bird" зі специфічними властивостями та поліморфним методом "getInfo()".
- **Комерційний облік**: Метод класу "PetStore" розраховує фінальну вартість тварини з урахуванням ПДВ (10%), додає запис до історії операцій та змінює баланс магазину.
- **Комбінована фільтрація**: На сторінці реалізовано три фільтри, які працюють одночасно в реальному часі:
  - За видом тварини (через випадаючий список);
  - За породою або забарвленням (динамічний пошук за текстом);
  - За максимальним віком (обмеження за числом).
- **Трифакторна валідація**: Форма покупки розділена на три обов'язкові інпути (Прізвище, Ім'я, По батькові) з програмною перевіркою методом ".trim()" на наявність порожніх значень або пробілів.
- **Інтерфейс**: Картки тварин адаптовані під світлий фон, містять стабільні веб-посилання на зображення, а блоки кнопок автоматично підлаштовуються під статус вакцинації без деформації сірки сторінки.

## Структура папок проєкту

```text
js-oop-variant-10
 ├── src
 │    ├── Pet.js         - Базовий клас та класи-спадкоємці тварин
 │    ├── PetStore.js    - Клас бізнес-логіки магазину та обліку фінансів
 │    └── app.js         - Основний скрипт ініціалізації, фільтрації та DOM
 ├── assets
 │    └── style.css      - Стилі інтерфейсу та адаптивної сітки карток
 ├── index.html          - Розмітка сторінки та модального вікна покупки
 └── README.md           - Документація проєкту
```
## Інструкція із запуску програми

1. Склонуйте цей репозиторій на свій локальний комп'ютер за допомогою Git.
2. Відкрийте кореневу папку проєкту `js-oop-variant-10` у середовищі розробки **CLion** (або іншій сумісній IDE від JetBrains).
3. Відкрийте файл `index.html` всередині редактора коду.
4. Наведіть курсор миші у верхній правий кут вікна коду та клацніть на іконку вашого браузера (наприклад, Chrome) для автоматичного запуску вбудованого локального вебсервера.
5. Програма автоматично розгорнеться за посиланням локального хоста `js-oop-variant-10/`.

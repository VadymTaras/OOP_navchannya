## 1. Архітектура та функціональні можливості

Проєкт являє собою повнофункціональну багатовіконну систему (Multiple Document Interface, MDI), побудовану за стандартом компонентної архітектури Windows Forms:

1. **Головне батьківське вікно (`ParentForm`):**
   - Властивість `IsMdiContainer = true` створює клієнтську MDI-область (`MdiClient`) для розміщення дочірніх вікон;
   - Колекція `MdiChildren` забезпечує централізований доступ, підрахунок та керування життєвим циклом усіх відкритих документів;
   - Властивість `ActiveMdiChild` відстежує активне дочірнє вікно в фокусі користувача.

2. **Головне ієрархічне меню (`MenuStrip`):**
   - Меню «Файл»: Створити новий документ (`Ctrl+N`), Відкрити (`Ctrl+O`), Зберегти (`Ctrl+S`), Зберегти як..., Закрити документ (`Ctrl+W`), Закрити всі, Вихід;
   - Меню «Правка»: Скасувати (`Ctrl+Z`), Повторити (`Ctrl+Y`), Вирізати (`Ctrl+X`), Копіювати (`Ctrl+C`), Вставити (`Ctrl+V`), Виділити все (`Ctrl+A`);
   - Меню «Вигляд»: налаштування шрифту (`FontDialog`), кольору тексту та тла документа (`ColorDialog`), перемикання видимості панелі інструментів та рядка стану;
   - Меню «Вікно»: алгоритми компонування дочірніх вікон `LayoutMdi` (`MdiLayout.Cascade`, `MdiLayout.TileHorizontal`, `MdiLayout.TileVertical`, `MdiLayout.ArrangeIcons`) та динамічний список відкритих вікон завдяки `MdiWindowListItem = menuWindow`;
   - Меню «Довідка»: модальне діалогове вікно `AboutForm`.

3. **Панель швидких інструментів (`ToolStrip`):**
   - Кнопки швидкого доступу для створення, відкриття, збереження файлів, операцій буфера обміну, розташування вікон та вибору шрифту.

4. **Контекстне меню (`ContextMenuStrip`):**
   - Спливаюче контекстне меню для робочої області редактора дочірніх форм із базовими командами редагування тексту.

5. **Інформативний рядок стану (`StatusStrip`):**
   - `lblStatus` — поточний стан програми та назва активного документа;
   - `lblCursorPos` — точні координати курсора (Рядок і Стовпчик у поточному документі);
   - `lblCharCount` — лічильник символів у тексті;
   - `lblDocCount` — динамічний лічильник відкритих MDI-вікон (`MdiChildren.Length`);
   - `lblClock` — системний цифровий годинник реального часу на базі таймера.

6. **Дочірня форма документа (`ChildDocumentForm`):**
   - Побудована на базі компонента `RichTextBox` (`Dock = Fill`);
   - Відстеження змін за допомогою прапорця `IsModified` з динамічним додаванням символу `*` до заголовка форми;
   - Захист від втрати даних: перевірка наявності незбережених змін у події `FormClosing` із запитом користувача (`Yes`/`No`/`Cancel`).

## 2. Структура файлів проєкту

```
Lab06_MDI/
├── Lab06_MDI.csproj             # Файл конфігурації проєкту .NET 8.0 WinForms
```

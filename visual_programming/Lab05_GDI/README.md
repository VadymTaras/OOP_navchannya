## 📌 Опис проєкту
Проєкт «Scientific Function & Geometric Graphics Plotter» демонструє практичне застосування графічної підсистеми **GDI+** (`System.Drawing`, `System.Drawing.Drawing2D`) у середовищі Windows Forms для побудови інтерактивних двовимірних графіків функцій, відображення координатних осей, налаштування векторних пер і пензлів, роботи з геометричними примітивами та експорту зображень.

### Реалізований функціонал:
1. **Полотно малювання із подвійною буферизацією (`DoubleBuffered`):**
   - Власний компонент `PlotterCanvas` із увімкненими прапорцями `OptimizedDoubleBuffer`, `AllPaintingInWmPaint`, `UserPaint`, `ResizeRedraw`, що повністю усуває мерехтіння графіки під час перемальовування та зміни розмірів вікна.
2. **Математичні функції для візуалізації:**
   - Тригонометричні функції: $\sin(x)$, $\cos(x)$.
   - Поліноміальні функції: парабола $x^2 - 4$, кубічний поліном $x^3 - 3x$.
   - Фізичні процеси: демпфовані затухаючі коливання $e^{-0.1x} \cdot \sin(2x)$.
   - Спеціальні функції: кардинальний синус $\text{sinc}(x) = \frac{\sin(x)}{x}$.
   - Хвильові явища: суперпозиція коливань $2\cos(x) + \sin(3x)$.
3. **Гнучке налаштування параметрів:**
   - Діапазон значень аргументу $[X_{min}, X_{max}]$ та крок табуляції $h$.
   - Налаштування пера `Pen`: вибір кольору через стандартний діалог `ColorDialog`, товщина лінії (1–10 px), стиль накреслення `DashStyle` (`Solid`, `Dash`, `Dot`, `DashDot`).
   - Напівпрозора градієнтна заливка підкриволінійної трапеції за допомогою `LinearGradientBrush`.
4. **Трансформація координат (World to Screen):**
   - Двостороннє перетворення між світовими математичними координатами $(X, Y)$ та екранними піксельними координатами $(S_x, S_y)$.
   - Автоматичне масштабування за обома осями з урахуванням пропорцій та відступів полотна.
5. **Координатна сітка та осі:**
   - Пунктирна сітка з числовими позначками.
   - Осі координат $OX$ та $OY$ з векторними стрілками (`AdjustableArrowCap`).
6. **Аналіз функції та інтерактивність:**
   - Автоматична детекція локальних екстремумів (Min/Max) із виведенням числових значень у точках перегину.
   - Інтерактивне відстеження позиції курсора миші над полотном: приціл (Crosshair), проекція точки на криву, відображення математичних координат $(X, Y)$ та $f(X)$ у рядку стану `StatusStrip`.
7. **Демонстрація геометричних примітивів GDI+:**
   - Прямокутники з двоколірним діагональним градієнтом (`LinearGradientBrush`).
   - Еліпси та кола (`FillEllipse`, `DrawEllipse`).
   - Багатокутники у формі зірки (`FillPolygon`, `DrawPolygon`).
   - Кругові сектори (`FillPie`, `DrawPie`).
8. **Експорт результатів у файл:**
   - Збереження графіка у форматах **PNG**, **BMP**, **JPEG** через діалогове вікно `SaveFileDialog` із високою роздільною здатністю за допомогою методу `Graphics.FromImage()`.

## 📌 Опис проєкту

Програмне забезпечення являє собою повнофункціональний інтерактивний додаток Windows Forms — **«Конфігуратор робочих станцій розробника ПЗ»** (Workstation Configurator). Додаток автоматизує підбір апаратних та програмних параметрів ПК, динамічний розрахунок вартості, формування деталізованої специфікації замовлення та експорт звіту у текстовий файл.

### 🛠️ Використані компоненти Windows Forms:
- **`MenuStrip`**: Головне багаторівневе меню додатку (`Файл` -> `Нове замовлення`, `Зберегти чек...`, `Вихід`; `Правка` -> `Скинути вибір`; `Довідка` -> `Про програму`).
- **`ComboBox`** (`DropDownStyle = DropDownList`): Вибір базової апаратної платформи процесора, оперативної пам'яті та графічного прискорювача з прив'язкою вартості.
- **`RadioButton`**: Взаємовиключний вибір пакету гарантійного обслуговування (12, 24 або 36 місяців) у межах контейнера `GroupBox`.
- **`CheckBox`**: Незалежний вибір додаткових послуг та компонентів (ліцензійна ОС Windows 11 Pro, додатковий SSD NVMe 2TB, рідинне охолодження 360mm, кабель-менеджмент, стрес-тестування).
- **`ListBox`**: Динамічний перелік включених модулів та пакетів ПЗ з можливістю додавання довільних компонентів користувачем через `TextBox` та їх видалення.
- **`RichTextBox`**: Виведення форматованої текстової специфікації замовлення з деталізацією цін та складових.
- **`StatusStrip` + `ToolStripStatusLabel`**: Живий моніторинг поточної орієнтовної суми замовлення та статусних повідомлень дій користувача.
- **`SaveFileDialog`**: Стандартний системний діалог збереження специфікації у текстовий файл.

## Опис проєкту

Додаток розроблено на платформі .NET Windows Forms. Він реалізує обчислення значень трьох математичних функцій за введеними аргументами `X` та `Y`:
1. $F_1 = \frac{\sqrt{X^2 + Y^2}}{X - Y}$ (з контролем ділення на нуль при $X = Y$);
2. $F_2 = \sin(X) \cdot \cos(Y) + \ln(|X|)$ (з контролем області визначення натурального логарифма $|X| > 0$);
3. $F_3 = e^{X - Y} + \tan(Y)$.

## 1. Огляд проєкту

Проєкт **«Async & Multithreaded Processing Hub»** являє собою наочну лабораторну станцію дослідження багатопотоковості та асинхронності в середовищі .NET 8.0 Windows Forms. Застосунок демонструє ключові парадигми фонової обробки даних, безпечну міжпотокову взаємодію з графічним інтерфейсом користувача (UI Thread) та аналіз наслідків блокування черги віконних повідомлень (UI Freeze).

### Реалізовані режими виконання:
1. **Сучасний підхід (async/await + Task.Run + Progress<T>):**
   - Виконання тривалих операцій у пулі потоків (ThreadPool);
   - Автоматична синхронізація зворотних викликів із головним потоком через `SynchronizationContext`;
   - Підтримка скасування за допомогою `CancellationTokenSource` та кооперативного токена `CancellationToken`.
2. **Класичний компонентний підхід (BackgroundWorker):**
   - Подієва модель Windows Forms (.NET 2.0+): `DoWork`, `ProgressChanged`, `RunWorkerCompleted`;
   - Вбудована підтримка звітування відсотків виконання (`WorkerReportsProgress = true`);
   - Скасування операцій через `WorkerSupportsCancellation = true` та виклик `CancelAsync()`.
3. **Прямий міжпотоковий виклик (Task.Run + перевірка InvokeRequired + Invoke / BeginInvoke):**
   - Демонстрація низькорівневого маршалінгу делегатів до черги віконних повідомлень форми;
   - Захист від критичного винятку `InvalidOperationException` («Cross-thread operation not valid»).
4. **Синхронний блокуючий виклик (Thread.Sleep у головному UI-потоці):**
   - Наочна демонстрація антипатерну: блокування циклу обробки повідомлень Windows (`Message Loop`);
   - Перехід форми в стан *«Не відповідає» (Not Responding)*;
   - Порівняння за допомогою інтерактивного «Клік-тесту чуйності UI».

## 2. Ключові можливості інтерфейсу:
- **ProgressBar** із плавним відображенням відсотків виконання (0..100%);
- **Метрики продуктивності в реальному часі:** розрахунок швидкості обробки (операцій/сек), точного витраченого часу та динамічного прогнозу закінчення роботи (**ETA**);
- **Повне керування життєвим циклом:** кнопки «Старт», «Пауза / Продовжити» (через `ManualResetEventSlim`) та «Скасувати операцію»;
- **Клік-тест чуйності UI:** спеціальна кнопка-лічильник, що демонструє збереження частоти кадрів (60 FPS) під час фонової роботи та повне зависання при синхронному виклику;
- **Журнал операцій у реальному часі (ListBox):** відображає точний час до мілісекунд `[HH:mm:ss.fff]`, ідентифікатор потоку `[Thread #ID]` та класифікацію (UI-потік vs Робочий потік пулу).

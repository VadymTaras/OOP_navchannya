## 📌 Опис проєкту
Проєкт демонструє побудову інтерфейсу користувача для керування табличними даними складського обліку товарів із використанням компонента `DataGridView` та механізму двостороннього зв'язування даних (`Data Binding`) через `BindingSource` та `BindingList<T>`.

### Реалізований функціонал:
1. **Різні типи колонок у DataGridView:**
   - `DataGridViewTextBoxColumn` — числовий ID, назва товару, ціна, залишок товару, автоматично обчислена підсумкова вартість.
   - `DataGridViewComboBoxColumn` — вибір категорії товару зі списку значень.
   - `DataGridViewCheckBoxColumn` — булевий прапорець наявності товару на складі.
   - `DataGridViewButtonColumn` — кнопка оперативної взаємодії («⚡ Списати 1 шт») для швидкого зменшення залишку в один клік.
2. **Зв'язування даних (Data Binding):**
   - Використання моделі даних `ProductItem`, що реалізує інтерфейс `INotifyPropertyChanged`.
   - Застосування `BindingList<ProductItem>` та `BindingSource` для автоматичної синхронізації змін між інтерфейсом і пам'яттю.
3. **Панель інструментів (`ToolStrip`):**
   - Додавання нових записів.
   - Видалення виділеного рядка із підтвердженням у діалоговому вікні.
   - Пошук та фільтрація в реальному часі за назвою або категорією.
   - Скидання фільтра.
   - Експорт даних у формати **CSV** та **JSON**.
   - Імпорт даних із файлів **CSV** та **JSON**.
4. **Валідація введених даних:**
   - Обробка події `CellValidating` для контролю заповнення обов'язкових полів (назва товару не може бути порожньою).
   - Перевірка коректності введення числових значень (ціна >= 0, кількість >= 0 ціле число).
   - Відображення тексту помилки валідації в комірці (`ErrorText`).
5. **Інформаційний статус-рядок (`StatusStrip`):**
   - Підрахунок загальної кількості записів.
   - Динамічний підрахунок сумарної вартості всіх активних позицій.
   - Відображення статусу останньої виконаної операції.

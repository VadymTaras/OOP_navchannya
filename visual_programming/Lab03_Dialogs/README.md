## 📌 Опис проєкту
Застосунок є розширеним текстовим редактором на базі **.NET 8 Windows Forms**, який демонструє роботу зі стандартними діалоговими вікнами та файловими потоками введення/виведення:
- `OpenFileDialog` — вибір та відкриття текстових файлів із фільтрацією за розширеннями.
- `SaveFileDialog` — збереження файлів з налаштуванням розширення за замовчуванням та перевіркою перезапису.
- `FontDialog` — вибір гарнітури, стилю та кеглю шрифту робочого поля.
- `ColorDialog` — гнучке налаштування кольорів шрифту та фону за допомогою повної RGB-палітри.
- `FolderBrowserDialog` — навігація по каталогах файлової системи, сканування та виведення аналітичної інформації про вміст папки.
- `StreamReader` та `StreamWriter` — надійне читання та запис даних у кодуванні UTF-8 із детальним перехопленням винятків (`try-catch-finally`).

Система управління задачами (Task Management System)

Проєкт реалізує об'єктно-орієнтовану модель управління списком задач (TODO-додаток) на базі сучасних стандартів мови JavaScript (ECMAScript 2015+). Робота демонструє практичні навички проєктування архітектури застосунку, використання геттерів, розрахунку бізнес-метрики за допомогою методів трансформації масивів та документування коду.

Структура сховища та архітектура даних

Проєкт побудований за модульним принципом і складається з двох основних класів:

1. Сутність Task (Об'єкт задачі)

Представляє інкапсульовану модель окремої задачі у системі.

Поля даних: Кожна задача містить унікальний id, текстові змінні title та description, рядкові мітки стану status та пріоритету priority, об'єкт дати dueDate для контролю дедлайнів, а також динамічний масив рядків tags.
Логіка стану: Зміна статусів реалізована через методи markComplete() та markIncomplete(). Взаємодія з масивом міток оптимізована за допомогою предикативних перевірок (includes) у методах addTag() та removeTag().
Динамічні обчислення: Використовується обчислювальний геттер isOverdue, який в режимі реального часу порівнює поточний системний час із встановленим дедлайном, враховуючи логічний стан виконання задачі.

2. Керуючий модуль TaskManager (Менеджер задач)

Реалізує шар бізнес-логіки для агрегації, пошуку та фільтрації колекцій об'єктів типу Task.

Маніпуляції з колекцією: Створення об'єктів делеговано методу createTask(), який інкапсулює конструктор сутності. Оновлення полів реалізовано через деструктуризацію параметрів у методі updateTask(), що дозволяє змінювати лише передані властивості.
Пошук та фільтрація: Методи вибірки використовують високоефективні методи перебору масивів ES6: filter() для групування за критеріями пріоритету чи тегів, find() для швидкого пошуку за унікальним ключем, та toLowerCase().includes() для забезпечення нечутливості до регістру (case-insensitive) під час контекстного пошуку searchTasks().
Аналітичний модуль: Розрахунок метрик у методі getStats() повертає комплексний зріз стану системи. Метод getTasksByDueDate() виконує складну трансформацію масиву в групований об'єкт за допомогою методу reduce(), де ключами виступають дати у форматі ISO рядків YYYY-MM-DD.

---

Технічний стек та вимоги

Платформа виконання: Node.js (версія 18.0 або вище) або сучасний веб-браузер із підтримкою ES-модулів (import/export).
Синтаксичні стандарти: ES6+ (стрілочні функції, деструктуризація об'єктів, класи, ключові слова const/let).
Документування: Повний специфікаційний опис методів і типів за допомогою JSDoc-коментарів.
Тестування: Модульне покриття (Unit testing) базових алгоритмів роботи з даними.

Інструкція зі встановлення та запуску

1. Клонування репозиторію

bash
git clone https://github.com/ваше-ім'я-користувача/назва-репозиторію.git
cd назва-репозиторію



 2. Встановлення залежностей для тестування


npm install



3. Запуск модульних тестів

Проєкт містить автоматизовані тести, які перевіряють коректність створення задач, валідацію дедлайнів та правильність математичного розрахунку відсотка виконання задач.


npm run test



4. Запуск демонстраційного сценарію

Для локальної перевірки працездатності системи без запуску тестового фреймворку виконайте команду:


node index.js

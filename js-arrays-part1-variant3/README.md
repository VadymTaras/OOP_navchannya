# Система управління завданнями (js-arrays-part1-variant3)

Проєкт представляє собою клієнтський вебдодаток для таск-менеджменту з гнучким інструментарієм аналітики, сортування та фільтрації масивів даних без залучення зовнішніх бібліотек.

---

## Структура проєкту

```text
js-arrays-part1-variant3
 ├── src
 │    ├── Task.js                 # Клас моделі окремого завдання
 │    ├── TaskManager.js          # Репозиторій та аналітичні методи обробки масивів
 │    └── app.js                  # Обробник інтерфейсу користувача та подій
 ├── assets
 │    └── style.css               # Адаптивні стилі інтерфейсу
 ├── index.html                   # Головна сторінка з панеллю управління
 └── README.md                    # Документація та опис архітектури

```

Опис структур даних та технічних рішень
1. Робота з масивами та обробка крайніх випадків
Уся бізнес-логіка програми зосереджена всередині класу TaskManager і базується на використанні ітераційних методів масивів стандарту ES6+:

Фільтрація (filter): Метод filterTasks здійснює багатофакторну перевірку об'єктів. Крайній випадок порожніх фільтрів (коли користувач обрав значення "Всі") обробляється за допомогою логічного заперечення !status || task.status === status.

Сортування (sort): Для кастомного сортування за пріоритетом впроваджено карту вагових коефіцієнтів { high: 3, medium: 2, low: 1 }. Обчислення різниці між ними дозволяє сортувати текстові поля як числові значення. Для збереження цілісності початкового масиву застосовується деструктуризація та копіювання через оператор spread [...this.tasks].

Агрегація статистики (reduce / filter): Розрахунок відсотка виконання та групування за унікальними категоріями реалізовано за допомогою методу reduce(), який збирає динамічний асоціативний об'єкт на льоту, запобігаючи помилкам дублювання ключів. Крайній випадок порожнього репозиторію (0 задач) перериває виконання та повертає нульові значення для уникнення помилки ділення на нуль (NaN).

2. Автоматичний контроль дедлайнів
Обчислення простроченого стану задачі відбувається за допомогою динамічного геттера get isOverdue() у класі Task. Метод автоматично порівнює поточну системну дату користувача із встановленим значенням дедлайну, попередньо обнуляючи часові значення годин (setHours(0,0,0,0)), що гарантує точність порівняння без похибок на часові пояси.

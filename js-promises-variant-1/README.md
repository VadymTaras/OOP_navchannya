# Система обробки замовлень їжі на нативних промісах (js-promises-variant-1)

Проєкт реалізує асинхронну подієво-орієнтовану модель конвеєра обробки замовлень їжі за допомогою послідовних ланцюжків нативних об'єктів `Promise`.

---

```markdown
js-promises-variant-1

 │    ├── order-processor.js      # Логіка функцій етапів замовлення на Promise
 │    └── app.js                  # Обробник подій інтерфейсу та запуск ланцюжка
 ├── assets
 │    └── style.css               # Адаптивні стилі лог-панелі та карток статусів

 └── README.md                    # Суцільний файл документації та інструкція

```

## Технічний опис асинхронної архітектури

### 1. Послідовні ланцюжки операцій (Promise Chaining)

Для виконання послідовних кроків обробки (перевірка → резервування → оплата → доставка) реалізовано класичний патерн проєктування "Ланцюжок промісів" (Promise Chaining). Замість вкладених функцій зворотного виклику (які призводять до Callback Hell), кожен метод повинен повертати новий екземпляр `Promise`. Наступний оператор `.then()` у ланцюжку автоматично очікує вирішення (`resolve`) попереднього промісу, передаючи трансформовані дані та ідентифікатор замовлення далі по конвеєру.

### 2. Централізована обробка виключень та помилок

Згідно з технічними вимогами, кожна асинхронна операція має вбудований 20% ризик виникнення асинхронного збою. Для запобігання падінню програми впроваджено централізований перехоплювач помилок через один термінальний метод `.catch()`. Якщо на будь-якому з етапів (наприклад, під час оплати в банку) проміс повертає стан `reject()`, виконання наступних блоків `.then()` миттєво припиняється, а керування асинхронним потоком безпечно делегується в загальний блок `.catch()`.

### 3. Гарантоване очищення стану додатка

Наприкінці ланцюжка інтегровано метод `.finally()`. Він виконується у будь-якому випадку — як при успішному завершенні доставки, так і при критичному збої транзакції. Метод використовується для відновлення працездатності інтерфейсу програми (розблокування кнопки надсилання замовлення) та логування завершення поточної асинхронної сесії.

## Інструкція із запуску програми

1. Склонуйте цей репозиторій на свій комп'ютер за допомогою команди Git.
2. Відкрийте кореневу папку проєкту `js-promises-variant-1` у середовищі розробки **CLion** (або іншій IDE від компанії JetBrains).
3. Відкрийте файл `index.html` всередині редактора коду IDE.
4. Наведіть курсор миші у верхній правий кут вікна коду та клацніть на іконку вашого браузера (наприклад, Chrome) для автоматичного запуску вбудованого локального вебсервера.
5. Сторінка розгорнеться у вкладці за посиланням локального хоста `http://localhost:63342/js-promises-variant-1`.
